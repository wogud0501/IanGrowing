- 이전 저장에 새 필드가 없어도 읽을 수 있으며, 중복 요청과 저장 실패 시 수량·결제·천장 복제를 방지합니다.
- 가방/장비/가챠/도감/확률을 기존 픽셀 UI 스택에서 별도 화면으로 제공합니다.
