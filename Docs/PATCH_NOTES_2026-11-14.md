# 이안 키우기: BLACK COMEDY EDITION — 누적 패치노트

- 작성일: 2026-11-14 (KST)
- 대상: Unity 6000.6.8f1 / macOS 개발 프로젝트
- 범위: 기존 성장·경제 시스템부터 Phase 2.6 생활 월드, Phase 2.7 주거, 개발자 QA Center, 최근 월드·UI·문 회귀 복구까지
- 최근 문 수정 체크포인트: `654bb05`

이 문서는 기존 구현 기록과 검증 결과를 정리한 누적 패치노트입니다. 아래 검증 수치는 각 작업 당시의 결과이며, 이번 문서 작성 과정에서 전체 게임을 다시 검사한 결과가 아닙니다. 전체 마스터 개발 요구사항의 완료 선언은 아닙니다.

## 주요 변경 사항

- 아동기인 7세부터 독립 외출이 가능하도록 성장 제한을 연결했습니다. 취업·금융 활동은 기존 19세 조건을 유지합니다.
- 직원이 한곳에 몰리던 업무 공간을 정리하고, 기존 직원 9명을 회사·증권·부동산의 실제 업무석과 일정에 연결했습니다.
- 길거리에 노출되던 증권·부동산 단말기를 각 시설 실내로 옮기고 기존 거래 기능을 유지했습니다.
- 부동산 매매, 전세·월세, 주거 대출, 시세와 주거 효과를 기존 경제·저장 시스템에 연결했습니다.
- F10으로 여는 개발자 테스트 센터와 격리 세이브, 상태 조작, 자동 검사·보고 기능을 추가했습니다.
- 문짝의 투명화·닫힌 문 잔상과 입장 시 문턱 정렬 오류를 수정했습니다.

## 성장·교육·직업·생활

### 기존 단계에서 누적된 기능

- 60개 미션 데이터와 챕터 진행, 조건 평가, 보상 수령 및 중복 보상 방지 구조를 유지합니다. 모든 미션에 대응하는 정식 서비스가 구현된 것은 아닙니다.
- 나이는 미션 성장 규칙에 따라 진행하며, 게임 날짜 경과만으로 자동 증가하지 않습니다.
- 교육 과정, 공부·숙제·시험·성적표·졸업과 진로 활동을 연결했습니다.
- NPC 친밀도, 친구 관계, 대화 제한·쿨다운과 관계 유지 처리를 추가했습니다.
- 지원 자격·면접·취업·근무·급여·경력·승진·퇴사·해고를 기존 직업 데이터에 연결했습니다.
- 자동 노동·공부·전투와 오프라인 정산을 추가했습니다. 기존 상한과 정산 시각 기록으로 같은 기간의 중복 보상을 방지합니다.

### 최근 성장 제한 복구

- UI, E키·터치가 공유하는 상호작용, 문 요청, 장소·씬 이동, 테스트 진입 및 직접 경제 실행 함수에 성장 조건을 적용했습니다.
- 0–6세의 독립 외출, 회사 이용, 취업·급여 및 성인 금융 활동을 제한했습니다.
- 유아기에는 침대에서 기존 돌봄 행동과 기초 생활 학습을 이용할 수 있도록 연결했습니다.
- 연령에 맞지 않는 장소에서 저장된 게임은 불러올 때 허용된 장소로 복귀합니다. 현금·보유 자산·미션·인벤토리를 초기화하지 않습니다.
- 교육 과정의 기존 연령·선행 조건과 원본 미션 ID를 유지했습니다.

## 경제·부동산·주거

### 경제 시스템

- 급여 기록, 세금 고지·부분 납부·체납, 원금·이자·연체·신용도 처리를 연결했습니다.
- 주식 매수·매도, 평균 원가, 평가·실현 손익, 가격 기록과 경제 뉴스 효과를 추가했습니다.
- 거래 ID와 정산 시각 기록으로 중복 거래·이자·시장 정산을 방지합니다.

### Phase 2.7 부동산

- 6종 매물의 목록·상세 조회, 매수·매각, 소유 평가액·실현 손익과 거래 기록을 추가했습니다.
- 전세·월세 계약, 보증금 지급·반환, 월세·관리비·미납, 계약 만료·해지를 연결했습니다.
- 반환받을 보증금은 자산으로 추적하며, 현금 반환과 자산 계산이 중복되지 않도록 처리했습니다.
- 주거 대출·상환·이자·신용도는 기존 부채 서비스를 재사용합니다.
- 지역·주택 유형·경제 뉴스·금리 영향을 반영하는 시세와 가격 기록을 추가했습니다.
- 기존 능력치와 휴식 처리에 주거 회복 효과를 연결했습니다.
- 총자산·순자산, 기존 미션 조건과 오프라인 자동 활동의 날짜 정산에 연동했습니다.
- 매물·보유·계약·대출·시세·기록 탭과 거래 확인 창을 연결했습니다.

### 초기 집 및 보존 규칙

- 새 게임의 일반 가구는 침대 하나로 시작합니다. 독립 화장실의 필수 고정 설비는 구매 가구와 구분합니다.
- 가구 구매와 이사에 기존 인게임 재화·소유 조건을 적용합니다.
- 회사·금융시설의 업무용 가구는 플레이어 개인 가구 소유 데이터와 분리합니다.
- 주택 유형별 전용 실내 아트 6종을 모두 추가한 것은 아닙니다. 현재 기존 주거 쉘을 재사용하는 범위가 있습니다.

## 도시·회사·NPC

- 별도 Workspace 씬을 새로 만드는 대신 기존 LifeWorld의 workplace 구역을 개선했습니다.
- 직원 ID 9개를 유지하면서 회사 5석·증권 2석·부동산 2석으로 업무 장소와 역할을 분산했습니다.
- 회사는 주간·야간 근무, 점심·휴게·귀가 일정에 따라 인원을 분산합니다.
- 고유 NPC ID에 따른 중복 인스턴스 방지와 좌석 예약·점유 처리를 연결했습니다.
- 회사의 부적절한 야외 벤치·노출 위생 설비를 정리하고 업무석, 실내 휴게 공간, 탕비 공간과 별도 화장실을 구성했습니다.
- 정면 업무 원화와 손·서류 프레임을 연결했습니다. 근무 중 빈 책상과 기존 옆모습 캐릭터가 겹쳐 보이지 않도록 처리했습니다.
- 증권·부동산의 기존 단말기 ID와 거래 UI를 유지하면서 실내 업무석·대기 공간·실제 시세·매물 안내를 연결했습니다.
- 기존 주민 2명에게 서로 다른 증권·부동산 상담 방문 일정을 추가했습니다. 상담 위치 예약, 시설 사용 기록과 다음 일정으로의 도보 퇴장을 확인했습니다.
- NPC가 문 앞 마지막 경로점에서 멈추던 오류를 수정했습니다. 격자점 반올림으로 닫힌 문짝에 걸리던 마지막 접근 구간을 실제 충돌 검사로 연결합니다.
- 출입구에 플레이어가 서 있으면 직원을 밀어내지 않고 대기하며, 통로가 비면 이동을 재개하는 흐름을 확인했습니다.

## UI 개선

- 기존 한글 폰트를 유지하면서 공통 종이색 픽셀 패널·버튼을 주요 씬에 적용했습니다.
- 메인 HUD의 표시 영역을 줄이고 장소·시간·재화·생활 상태를 정리했습니다.
- 부동산 상세 이미지·설명·매물 목록의 반응형 배치를 개선했습니다.
- 레이아웃 확정 전 폭을 저장해 일부 매물 카드가 잘리던 문제를 수정했습니다.
- 헤더·탭·거래 버튼·피드백·스크롤 영역의 높이와 간격을 조정했습니다.
- 연령 조건에 맞지 않는 거래는 잠금 상태와 안내를 표시하며, 실행 함수에서도 거부합니다.
- 1280×720, 1920×1080, 904×2316, 1840×2208 등 작업별 지원 화면에서 경계·텍스트 검사를 수행했습니다. 실제 기기의 터치 사용성 검증과는 구분합니다.

## 문 개폐·입장·퇴장 수정

### 문짝과 문틀 표현

- 문 뒤에 플레이어가 있을 때 문짝까지 알파 0.32로 낮추던 처리를 제거했습니다.
- 고정 문틀에 닫힌 문 이미지 전체가 남던 메시 문제를 수정했습니다. 문틀은 네 테두리만 표시합니다.
- 기존 선택 하이라이트가 옛 문 이미지를 덧그리던 현상을 제거하고 실제 문틀의 색상 피드백으로 변경했습니다.
- 기존 문 텍스처를 두께 있는 문짝 메시의 앞면·뒷면·상단·측면에 사용합니다. 경첩을 기준으로 회전한 형태를 2.5D 화면에 투영합니다.
- 유리문은 폭을 줄이는 대신 두께 있는 두 패널을 각각 이동시킵니다.
- 여닫이 문은 설치 방향에 따른 한 방향 개폐를 유지합니다. 접근 방향 때문에 경첩이나 손잡이가 FlipX로 바뀌지 않습니다.
- 문틀·Root·기존 경첩 Transform의 고정 상태와 기존 개폐 상태 관리 주체를 유지했습니다.

### 입장 정렬과 타이밍

- 회사 정문의 비주얼 Y=4.00과 실제 문턱 Y=3.55처럼 입장 문에서 발생하던 0.45~0.5 단위 차이를 수정했습니다.
- 입장 비주얼과 개구부 음영을 실제 문턱에 맞췄습니다. 음영이 간판·바닥 쪽으로 삐져나오던 부분도 정리했습니다.
- 기존 퇴장 방향 비주얼, Collider와 포털 도착 좌표는 유지했습니다.
- 접근·통과는 기존 로컬 좌표계와 Rigidbody 발 위치를 사용합니다. 문이 열린 상태와 통과 완료를 확인한 뒤 기존 장소 전환을 실행합니다.
- 이동 타임아웃을 실제 FixedUpdate 시뮬레이션 시간에 맞춰 프레임 지연·일시정지와 이동 처리가 어긋나는 문제를 보완했습니다.
- 폐점 후 상점 출구까지 막히던 오류와 파괴된 플레이어 참조 접근을 수정했습니다. 명시적인 문 잠금은 계속 적용합니다.
- 문 점유·공동 사용·중복 입력 거부와 기존 E키·모바일 공통 상호작용 경로를 유지했습니다.

## Developer QA Center

- Editor와 Development Build에서 F10 또는 Editor 메뉴로 여는 개발자 오버레이를 추가했습니다.
- 현금·부채·신용·나이·날짜·능력치 조작과 실제 시간·오프라인 정산 시뮬레이션을 연결했습니다.
- 분류·검색, 선택 검사·전체 검사·실패 항목 재실행, 진행률, 진단, 로그·보고서 저장을 지원합니다.
- 실제 서비스 실행 결과에 따라 PASS / FAIL / NOT IMPLEMENTED / BLOCKED / MANUAL 등을 구분합니다. 미실행·미구현 기능을 PASS로 표시하지 않습니다.
- QA 전용 저장 채널과 상태 스냅샷을 사용하며 종료 시 원래 모델·씬·설정을 복구합니다.
- 신규 기능의 시나리오를 등록할 수 있는 레지스트리와 Unity Test Framework 연결을 추가했습니다.
- Release/Development 스크립트 컴파일과 심볼 검사로 Release에서 QA 코드가 제외되는 것을 확인했습니다.

## 저장 및 안정성

- 기존 v4 저장에 필요한 선택적 필드만 확장하고, 빈 인라인 계약·보고서 객체를 유효 데이터로 오인하지 않도록 정규화했습니다.
- 미션·경제·직업·교육·주식·가구 데이터를 재사용하며 원본 60개 미션 에셋과 공식 이안 원본 이미지를 유지했습니다.
- QA와 자동 검사의 시작·종료 시점에 운영 세이브를 덮어쓰지 않도록 전용 슬롯과 쓰기 보호를 적용했습니다.
- 작업별 백업·해시·복구 기록을 보존했습니다. 이전 단계의 자동 저장 변동과 복구 이력도 별도 기록에 남아 있습니다.
- 마지막 문 작업의 종료 해시는 해당 작업 중 관측한 세이브와 일치합니다. 이를 모든 세션 시작 시점의 세이브가 동일했다는 의미로 해석하지 않습니다.
- 마지막 문 작업 종료 시 LifeWorld / Edit Mode / StandaloneOSX / 씬 dirty=false를 확인했습니다.
