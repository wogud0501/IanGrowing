# 주민과 이안의 침대·이불 검증

Unity 6000.6.8f1, macOS 개발용 독립 실행 빌드, 1280 × 720. 전용 테스트 세이브로 게임에 등록된 방을 열었다. 각 취침과 기상 직전에 시각을 맞춘 뒤 스케줄과 보행·문·침대 예약·애니메이션을 실제 프레임으로 재생했다. 이안은 자기 침대의 일반 수면 상호작용을 사용한다.

## 무엇이 바뀌었나

이전에는 주민의 물리 루트와 침대 수면 좌표가 섞였다. 이제 보행과 충돌은 침대 옆에서 끝나고, 같은 사람의 별도 렌더러가 앉기·기울이기·눕기·이불을 잡는 손·수면 자세를 표시한다. 베개와 이불은 매트리스의 로컬 좌표를 쓴다. 이불은 발치에 남으며 상단이 올라가거나 내려온다. 수면 중 천과 몸은 한 호흡 주기를 공유한다. 퇴장 때 예약은 일어나기와 침대 옆 복귀 후 해제한다. 수면 시간과 회복의 정산은 기존 행동 서비스가 담당한다.

기존 세이브가 잠든 시각이면 주소·스케줄·개인 침대로 수면 자세를 다시 구성한다. 이불을 끌던 도중의 소수점 프레임은 저장하지 않는다. 부모는 각자의 원래 얼굴과 실내복으로, 주민은 네 기존 외형 계열로, 이안은 성장 단계별 외형으로 렌더링한다. 첫 촬영에서 여러 날을 연속으로 건너뛰다가 테스트 캐릭터가 갈증으로 게임 오버가 되었다. 해당 시점 이후의 화면은 결과에서 제외하고 별도 세이브에서 재생했다. 부모 침실에서는 플레이어가 문을 점유하자 NPC가 문 앞에서 기다렸다. 플레이어를 벽장 쪽으로 옮기니 정상 입장했다.

## 저장·재접속

301호 23시대에 두 주민이 누운 화면에서 수동 저장했다. macOS 프로세스를 종료한 뒤 같은 슬롯으로 타이틀의 이어하기를 선택했다. 같은 301호와 플레이어 위치가 복원됐다. 정호는 `resident-bed-7`, 어르신은 `elder-301-bed`의 점유자로 다시 나타났다. 양쪽 모두 이불이 덮인 상태였다. 06:31에 어르신이 먼저 이불을 걷고 일어났을 때 정호는 자기 침대에서 계속 잤다. [재접속 직후](ResidentialRebuild/Continue301.jpg)

저장 전후 JSON에서 동일한 실행 ID, 플레이어 나이·상태·위치, 인벤토리·장비, 관계, 미션·보상 수령 내역을 대조했다. 두 주민의 집·침대·위치·행동·완료 키도 일치했다. 재접속 사이 게임 시계가 2분 진행됐고 기존 시장 시스템이 금융·부동산 시세와 시세 갱신 번호를 갱신했다. 현금은 750G, 친구 수는 1로 유지됐다.

19세 독립 집에서도 현관에서 침대까지 걸어간 뒤 일반 상호작용으로 잠들었다. 20시대에 누워 다음 날 04시대에 침대 옆에서 조작이 복구됐다. 실내복 차림의 얼굴과 베개가 이불 위에 남는 것을 확인했다. [19세 이안의 침대 연속 화면](ResidentialRebuild/IanIndependentSleep.jpg)

이번에 직접 플레이한 이안은 9세와 19세다. 다른 연령의 이전 검증 기록은 [성장 단계별 수면 검증](SLEEP_ANIMATION_QA.md)에 있다. 이번 실행에서는 11개 성장 외형의 프레임 자산과 0세 이동 제한을 PlayMode 테스트에서 확인했다. Android·iOS 실기기와 모든 연령의 재촬영은 이번 macOS 촬영 범위 밖이다.
