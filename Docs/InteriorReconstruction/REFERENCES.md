# 확인한 참고자료

- 사용자 첨부 원본을 `02_AI_Bathroom_Art_Direction.png`로 보존했다. 콘셉트의 전체 이미지는 Unity 배경으로 사용하지 않았다.
- 이 세션의 수정 전 Game View를 `01_Current_Unity_Bathroom.png`로 실제 촬영했다. 명시된 두 파일명은 작업 디렉터리에 없었으므로 첨부와 실제 재촬영으로 구분했다.
- [Fields of Mistria 공식 presskit](https://www.fieldsofmistria.com/presskit): 페이지와 공식 주택 가구 배치 GIF 첫 프레임을 확인했다. 방 경계를 명확히 하고 UI를 주변으로 분리하는 방식을 관찰했다.
- [Eastward 공식 media](https://eastwardgame.com/media/): 공식 스크린샷을 확인했다. 이번에 직접 본 이미지1/4는 도시 장면이며 실내라고 분류하지 않는다. 제한된 색과 접지 그림자·층 구분을 참고했다.
- [Stardew Valley Spa 이미지 페이지](https://stardewvalleywiki.com/File:Spa_Interior.png): 페이지와 원본 이미지 링크를 읽었으나 원본 다운로드가403으로 차단됐다. 실제 이미지를 보았다고 주장하지 않는다.
- [Potion Permit 리뷰](https://www.elsotanoperdido.com/analisis/potion-permit/2022092252806): 페이지와 스크린샷 링크를 확인했다. 해당 리뷰 이미지가 욕실이라는 근거는 없으므로 욕실 구조를 검증한 자료로 사용하지 않았다.

상업용 스크린샷은 관찰용 로컬 백업 폴더에만 보관하고 Assets로 복사하지 않았다. 새 `FamilyBathroomModules.png`는 built-in image_gen으로 사용자 콘셉트에 맞춰 생성한6개 모듈 아틀라스다. 앞3개 타일 영역과 수납장/수건걸이/선반을 별도 Sprite 에셋과 GameObject로 배치했다. 이안/세면대/변기/샤워/출입문 기본 아트는 기존 에셋을 재사용했다.
