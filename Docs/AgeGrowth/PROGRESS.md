## 남아 있는 품질 범위
- 생성한 아트는 인간의 최종 픽셀 정리·공식 디자인 검수가 필요.
- 어린 연령의 생활 동작은 Down 방향 중심. 이동은 4방향 전용 프레임이 있으나 모든 상호작용의 4방향 신규 아트가 완성된 것은 아님.
- Turn/Stop은 Idle을 재사용하며, 연령별 미제작 감정·일부 행동은 해당 연령 Idle로 대체. 성인 아트를 어린 캐릭터 fallback으로 사용하지 않음.
- 보호자 목욕의 손 포함 연출은 구현됐지만, 부모 NPC 전신의 요청 수신→다른 방에서 이동→안고 운반하는 전체 연결은 미완료.
- Profile의 hand/eye 등 일부 기준점은 데이터이며 모든 가구의 손 IK/연령별 상세 정렬에 적용된 것은 아님.
- Android/iOS 실기기·폴더블 실기기는 미검증.
