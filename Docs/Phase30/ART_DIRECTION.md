# Phase 3.0 현재 아트 기준

우선 이미지: [사용자가 마지막에 제공한 24장면 시안](ArtDirection-Current.png). 이전 보라색 중심 시안보다 이 자료를 우선합니다.

- 차콜·웜그레이 공간 외곽, 크림 종이, 바랜 금색 테두리. 보라색·네온은 특정 장소의 조명에 제한하고 공통 UI의 기본으로 쓰지 않습니다.
- 부모님 집: 따뜻한 생활 조명과 나무·천·수납의 질감. 독립 초기는 같은 밀도로 가구를 채우지 않습니다.
- 도시: 낮/저녁/밤의 대비. 기존 교통·가로등·간판·시설별 생활 애니메이션을 보존하고 재사용합니다.
- 인벤토리와 가챠: 차콜 패널, 종이/사진 카드, 금색 버튼, 영수증. 한 화면에 모든 메뉴를 추가하지 않습니다.
- 이안: 공식 검은 머리·피곤한 눈·검은 옷·목의 헤드폰·슬리퍼 유지. 시안의 다른 복장이나 상표를 그대로 가져오지 않습니다.
- 실제 스프라이트는 Point 필터와 투명 PNG, 일관된 앵커로 적용합니다. 시안 전체를 배경 한 장으로 붙이지 않습니다.
- 나이는 기존 데이터가 기준입니다. 중년30~59/노년60+이며 시안의 예시 나이와 게임 권한은 구분합니다.

원화 파일, 패널/버튼 재료는 built-in imagegen 파생 제작. 원본 공식 캐릭터 파일은 변경하지 않았습니다. UI 9-slice와 재료 추출은 Unity authoring 단계에서 처리했습니다. 생성 이미지를 실제 게임의 검증 완료 화면으로 대신 제출하지 않습니다.
