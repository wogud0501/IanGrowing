# 첫 플레이와 성장 안내

출생 신고서를 닫으면 화면 왼쪽 위에 현재 미션과 짧은 생활 안내가 보인다. 카드를 누르면 현재 가능한 행동을 최대 세 가지까지 확인할 수 있다. 메뉴의 **시스템 → 도움말**에서도 같은 화면을 열 수 있다. 잠깐 켜지는 흰색 표시로 상태 수치나 상호작용 대상을 찾을 수 있다.

## 플레이 흐름

| 시점 | 안내가 나타나는 조건 | 완료를 판단하는 기준 |
| --- | --- | --- |
| 영아기 | 현재 방에서 가능한 돌봄과 허기·수분 수치 | 식사 후 허기 증가, 물을 마신 뒤 수분 증가, 수면 행동 성공 |
| 첫걸음 | 성장 서비스가 보행을 허용 | 조작 가능한 상태에서 실제로 0.65 월드 단위 이동 |
| 주변 상호작용 | 보행 후, 사용할 수 있는 대상이 가까이 있음 | 대상의 선택창을 열거나 행동·문 이동에 성공 |
| 미션과 상태 | 기본 생활을 경험 | 미션 창이나 상세 상태를 직접 열기 |
| 도시와 학교 | 독립 외출·교육 권한, 현재 위치와 시설 운영 시간 | 실제 도시 또는 시설에 입장. 가족 대화는 관계 변화, 사회 활동은 성공한 행동으로 확인 |
| 물건과 장비 | 아이템, 장비, 헤드폰 첫 획득 | 실제 인벤토리 열기 또는 해당 슬롯에 장착 |
| 직업과 금융 | 취업·금융 해금, 첫 급여, 세금 고지서, 부채가 있는 명세서 | 회사 입장, 명세서 열기, 투자 단말기 열기. 가챠는 확률표 열기 |
| 독립 | 실제 독립 거처에 처음 입장 | 새집에서 잠을 자거나 외출. 소득과 가격을 충족하면 가구 구매 안내. 실제 구매로 완료 |

새 게임의 허기와 수분은 모두 100이다. 이때는 침대에서 먼저 잘 수 있다. 이후 수치가 내려가면 돌봄을 안내한다. 먼저 다른 일을 한 플레이어의 경험도 기록한다. 보상 수령과 성장 판정은 기존 미션 시스템이 담당한다.

긴급한 생존 행동을 우선 추천한다. 대상이 멀면 장소와 다음 문을 안내하고, 잠긴 시설과 닫힌 상점은 후보에서 거른다. **안내 건너뛰기**에는 확인 단계가 있다. 건너뛴 뒤에도 추천을 사용할 수 있다. **생활 도움말 → 기본 안내 다시 시작**은 안내 기록만 초기화한다.

## 저장과 재검증

기존 도시 생활 저장 블록에 단계별 미시작·진행·완료·건너뜀을 기록한다. 이전 세이브는 기존 성장 권한, 거주 상태, 장착품과 경제 기록으로 경험한 안내를 판별한다. 개발용 QA 센터의 `city/onboarding-save`에서 건너뛰기와 재시작, 디스크 복원, 미션·잔액 보존을 다시 검사할 수 있다. `city/first-outing`은 7세 이안을 매 출입구의 상호작용 반경 가장자리에 배치한 뒤, 일반 출입 동작으로 세 문을 연속 통과하는지 검사한다.

| 관찰한 지점 | 바꾼 내용 | 검증 |
| --- | --- | --- |
| 0세 도움말에 WASD가 나왔고 돌봄 메뉴의 위치가 불분명했다 | 걸을 수 있을 때만 이동을 설명하고, 잠자리와 돌봄 선택지의 실제 이름을 표시했다 | 신규 세이브에서 수면 후 허기 98·수분 96, 식사 후 허기 100, 음수 후 수분 100 확인. 이미 100인 상태에서 먹어도 식사 학습이 완료되지 않았다. |
| 키를 눌러도 이안이 벽이나 침대에 막힐 수 있었다 | 누른 키가 아닌 플레이어의 누적 실제 이동을 관찰한다 | 포커스가 있는 Game View와 macOS 플레이어에서 이동 후 첫 상호작용으로 전환. 순간 위치 변경과 씬 이동만으로는 완료되지 않았다. |
| 수분이 낮을 때 부모님 집의 식수 위치를 찾기 어려웠다 | 실제 거실 식수 위치와 경로를 표시한다 | 낮은 허기·수분을 준비한 뒤 두 생존 행동이 추천 상단에 나타나는지 확인했다. |
| 독립한 순간 생존 안내가 새집 설명을 가릴 수 있었다 | 첫 입주 시 독립 안내를 보여주고 생존 행동은 추천 목록 첫 자리에 남긴다 | 19세 입주, 지급된 급여, 실제 가구 구매와 저장 복원 확인. |
| ‘사흘 동안 살아남기’가 짧은 휴식만 안내했다 | 날짜 변경이 조건임을 설명하고, 침대에서 게임 시간 8시간을 보내는 수면을 추천한다 | 신규 세이브에서 0/3일부터 3/3일까지 진행해 보상 수령과 7세 외출 해금을 확인했다. |
| 7세가 문 사용 범위 끝에서 외출을 시도하면 방 안으로 되돌아왔다 | 고정된 접근 제한 시간을 어린 이안의 실제 보행 속도와 남은 거리로 계산한다. 골목에서는 도시로 이어지는 다음 길을 알려준다. | 동일 반경에서 이안의 방 → 거실 → 골목 → 도시 중심의 세 문을 실제로 사용했다. |

## 검증 환경과 저장 파일

Unity 6000.6.8f1의 Game View와 macOS 개발 플레이어에서 신규 게임을 실행했다. 입력과 UI 선택은 자동화했다. 신규 이용자를 모집한 관찰 조사와 휴대전화·실제 패드 시험은 수행하지 않았다. 세로 화면은 1080 × 1920 Game View, 패드는 Unity Input System의 가상 기기로 검사했다.

- 수분·허기 부족, 심야 상점, 외출·학교, 실제 장착, 확률표, 급여·세금·명세서, 첫 독립 집과 가구 구매, 이전 세이브와 건너뛰기를 포함한 Play Mode 검사 61개를 통과했다. 후반 조건을 준비할 때는 연령, 잔액과 대상 위치를 설정했다. 완료 판정에는 일반 게임 서비스와 UI를 사용했다.
- 별도 입력 검사에서 패드로 전환하자 HUD와 주변 행동 안내가 함께 바뀌었고, 키보드로 돌아오자 둘 다 E를 표시했다. 세로 화면 도움말에서 잘린 TMP 텍스트는 없었다.
- 초기 macOS 개발 빌드는 검은 화면에서 시작했다. 기본 렌더 파이프라인에 기존 PC용 URP 에셋을 지정한 뒤 재빌드해 출생 화면과 월드를 확인했다.
- 초기 병렬 검증에서는 서로 다른 이름의 macOS 테스트 앱들이 같은 번들 식별자를 공유했다. 종료 시 기존 기본 자동 저장이 갱신돼 보존 해시 검사가 실패했다. 이 슬롯은 19세였고, 기본 파일과 직전 백업의 성장·미션·아이템·스탯은 일치했다. 시간, 주민 상태, 시세와 뉴스, 약관 기록에는 차이가 있었다. 실행 전 기본 파일과 일치하는 사본을 찾지 못해 이전 값으로 되돌리지 않았다. 프로젝트 Editor 슬롯은 별도 경로에 있다. 이후 신규 앱 식별자와 저장 경로를 실제 플레이어에서 확인하고, 테스트 종료 시 기본 슬롯의 자동 저장을 끄고 검증했다.
