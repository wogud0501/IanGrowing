# 패치노트 — 성장 외형 및 생활 동작 연결 (2026-11-15)

중단된 9단계 성장 작업을 이어 실제 분리 씬 16개에 적용했다.

- 0세부터 성인까지 서로 다른 9개 외형 뱅크 연결. 성인 원본과 기존 6단계 생애주기는 유지.
- 보행 1세 / 독립 외출 7세 / 선택적 독립 19세 조건 분리 유지.
- 연령별 실제 Sprite, Collider, 보폭·속도 갱신. 나이에 따라 캐릭터 Transform Scale을 바꾸지 않음.
- 영아·유아 침대, 실제 수면·기상, 이불/난간 가림, 어린 연령 식사 연결.
- 신생아 울음·수유, 유아 물 마시기, 보호자 손 포함 목욕 연출 추가.
- 0~2세 단독 샤워와 0세 직접 문 통과를 실행 단계에서 제한.
- 행동 중 성장 변경 지연, 취소 시 점유·충돌·입력 복구.
- QA 센터 성장 경계 검사와 외형 프리셋 9개, 개발용 비교 화면 추가.
- 로드 시 나이에서 외형을 재계산하고 원본 세이브 3개 해시 보존 확인.
- Play Mode 12개 시나리오 931 assertions, Unity Test Framework 테스트 2개 통과.
- Android ARM64 IL2CPP Development 빌드 성공. iOS SDK 부재로 iOS 빌드는 미검증.

최종 원화 승인, 모든 방향의 생활 동작 아트, 가구 전체의 손/시선 정렬, 부모 NPC 전신 돌봄 이동, 실기기 검수는 남아 있다.
