# 플레이어 피드백 개선 검증

2026-11-22 · Unity 6000.6.8f1 · macOS Standalone 개발 빌드, Android 15/API 35 에뮬레이터. 플레이 기록은 전용 앱 ID의 로컬 저장 슬롯에서 수집했다. 신규 게임에서는 이동 입력, 현장 상호작용, 메뉴 버튼을 자동 조작했다. 미션 강제 완료 명령은 사용하지 않았다. 주민 시간표 표본 검증에서는 게임 시각을 바꾸고 현관 출입을 별도로 연속 관찰했다.

## 초반 미션

| 피드백 | 확인한 원인 | 반영 및 검증 |
| --- | --- | --- |
| M014 첫 친구에서 정체 | 일반 대화가 하루 상호작용 기회를 소비했다. 별도의 친구 행동은 확률 판정에 실패할 수 있었고, 저장된 친구 관계가 있어도 이벤트 카운터만 읽었다. | M014가 진행 중이면 조건에 맞는 또래와 첫 대화가 친구 관계를 만든다. 민수와 준서를 서로 다른 새 게임에서 각각 만나 일반 대화로 1/1을 달성했다. 준서는 대화 전에 저장·재실행한 뒤 만났다. 두 경우 모두 보상을 수령하고 M015에 진입했다. Android에서는 같은 날 민수와 이미 일반 대화를 했던 저장도 재현해, 한 번 더 대화하면 친구가 되는 것을 확인했다. [미션 화면](PlayerFeedback/Friend.jpg) |
| 누구에게 말해야 하는지 불분명 | 교사·상점 직원과 또래 학생의 기능이 다르고, 학생 위치가 시간에 따라 바뀐다. | 미션에 현재 대화 가능한 주민의 이름과 장소를 표시한다. 위치 확인을 누르면 이동할 문을 안내한다. 학생들이 자는 시간에는 다음 등교 시간을 안내한다. 관계를 만들 수 없는 NPC는 진행도를 올리지 않는다. |
| 초반 단순 반복 | 독서 3회, 초등 숙제 5회가 필요했다. 독서만 줄인 첫 빌드에서는 다음 지식 목표가 다시 독서를 유도했다. | 독서와 첫 숙제를 각 1회로 조정했다. 다음 미션은 수업 1회 또는 기존 지식 20으로 달성한다. 새 게임에서 책 한 번, 수업 한 번, 지식 12로 M014에 도달했다. 첫 물 마시기는 기존에도 1회였다. |
| 첫 외출까지 4일 | 시작일을 빼고 경과일 3일을 요구했다. | 경과일 2일로 바꿨다. 1일째에 시작한 세이브에서 3일째 유아기를 졸업했다. 7세에 이안 방 → 거실 → 주거 골목 → 도심 → 학교를 실제 문으로 걸어 이동했다. |
| 구버전 저장 | 이전 조건의 진행도와 관계·보상 영수증을 따로 보관한다. | 독서 2/3, 기존 친구 민수, 친구 카운터 0, 지급 영수증이 남은 저장을 재현했다. 이어하기에서 독서·기존 지식·친구 순서로 인정되어 M015로 진행했다. 수령 전후 잔액은 750G였다. |

## 주거지와 길 찾기

- 공동 침실을 사용하던 주요 주민 15명을 13세대에 배정했다. 학생 두 명은 각각 가족과 살고, 세대별 침대와 소파 자리는 주민 ID로 배정한다. 같은 건물 현관에서 호수와 이름을 골라 방문한다. 한 번에 한 집의 내부만 로드한다. 이전 저장의 공용 주거지 참조를 개인 주소로 변환한다.
- 주택과 가구 시트는 Higgsfield GPT Image 2.6에서 각각 생성했다. 선택한 가구를 투명 스프라이트로 분리해 조리대·싱크대·식탁 등 개별 오브젝트에 적용했다. [아트 기록](HIGGSFIELD_ASSET_MANIFEST.md)
- 시간대 샘플링에서는 집에서 세면·식사, 외출과 학교·직장, 저녁 귀가, 야간 취침이 확인됐다. 현관을 연속 관찰하면서 침대 곁 수납장이 학생의 이동을 막는 별도 결함을 발견했다. 침대 발치로 접근하고, 휴식은 지정 소파에서 하도록 바꿨다. 방문객이 주민 현관 통로를 막지 않도록 입장 위치도 옆으로 옮겼다. 민수가 집에서 주거 골목으로 나가고, 저녁에 자신의 소파로 돌아와 휴식한 뒤 102호 침대에서 자는 것을 다시 확인했다. [102호 취침](PlayerFeedback/Household.jpg)
- 주거지역과 도심 양쪽에서 미니맵과 확장 지도를 열고 실제 문으로 왕복했다. 지도 좌표는 현재 구역의 문과 플레이어 위치를 사용한다. 두 표지판의 한글은 Unity에서 렌더링한다. [주거지역 지도](PlayerFeedback/ResidentialMap.jpg) · [도심 지도](PlayerFeedback/CityMap.jpg) · [양방향 표지판](PlayerFeedback/Signs.jpg)
- Unity 주민 주간 검증은 집별로 같은 템플릿을 따로 구성하고 각 시간표의 장소, 활동 앵커 및 좌석 중복을 검사한다. 주민 25명, 게임 내 7일을 통과했다. 런타임에서는 학생·회사원·상점 직원 표본을 시간대별로 관찰했다.

## 메뉴와 모바일

생활·아이템·금융·시스템 탭으로 나누고, 기능을 소개하던 상시 문단과 중복 바로가기를 줄였다. 상태 아이콘은 식기·물방울·심장·머리 형태로 다시 그리고 짧은 한글 이름을 붙였다. 세로·가로·태블릿 비율에서 배치를 확인했고 Android 1080×2400 화면에서 HUD·생활 메뉴·지도를 캡처했다. [Android 화면](PlayerFeedback/Android.jpg)

## 검증 범위

Unity PlayMode 회귀 테스트 13개가 통과했다. 집 안팎의 관찰에서는 로드된 게임 씬 1개를 확인했다. Android는 에뮬레이터 결과이며 실기기의 발열·배터리·지속 프레임과 iOS 실기기 터치는 이번 검증 범위에 포함되지 않았다.
