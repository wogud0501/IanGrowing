# 이안 키우기 — Phase 2.8 패치노트

2026-11-16 · 도시 생활 UX

## 도시 주민
- 같은 위치로 접근하던 NPC가 서로 겹치는 이동 판정을 수정했습니다.
- 주민별 개인 공간과 도시 목적지를 확보하고, 막힌 주민은 기다린 뒤 주변 점유를 반영한 경로 재탐색과 유지되는 우회 지점을 사용합니다.
- 생성 및 저장 위치 복원에서 도시 점유 검사를 수행합니다.
- 도로 밖 횡단을 유도하지 않도록 우회·스폰 후보에 기존 보도/횡단보도 범위를 적용했습니다.
- 기존 출퇴근·학교·상점·귀가 시간표와 차량·신호 시스템을 유지하며, 횡단보도에는 진행 방향별 보행 차선을 적용했습니다.

## 지도와 길 안내
- 도시에서만 작은 미니맵을 표시합니다. 플레이어 위치·방향과 실제 시설 출입구를 표시합니다.
- 전체 지도에서 시설을 선택해 가능한 행동과 연령 제한을 확인할 수 있습니다.
- 목적지를 지정하면 다음 출입구를 안내합니다. 순간이동이나 퀘스트 잠금은 추가하지 않았습니다.
- 처음 방문한 시설을 발견 기록으로 저장합니다. 필수 주거·학교·상점은 처음부터 알아볼 수 있습니다.

## 생활 가이드
- 상태와 성장 단계에 맞는 선택적 추천 행동을 제공합니다. 가이드 화면에서 숨길 수 있습니다.
- 첫 방문에는 시설 설명을 제공하고, 재방문에는 상호작용 안내를 간결하게 표시합니다.
- 별도 도전과제 화면에 첫 걸음·외출·상점 방문·구매·식사·근무·급여·친구·수업·가구 구매/배치·이사·투자·하루 완주·시설 발견을 추가했습니다.
- 기존 실제 성공 이벤트로 진행하며, 도전과제 자체는 돈이나 물품을 지급하지 않습니다.

## UI와 저장
- 기존 한글 픽셀 폰트·패널·아이콘을 재사용하고 지도/도전과제/가이드를 별도 화면으로 분리했습니다.
- 발견 장소, 목적지, 진행률, 완료 도전과제, 가이드 열람, 추천 숨김 설정을 기존 저장 데이터에 추가했습니다.
- 보행 1세 / 독립 외출 7세 / 기존 성인 및 독립 조건을 유지합니다. 기존 Scene ID·문 코어·회사 레이아웃은 유지됩니다.

검증 결과와 미검증 범위는 [최종 결과](Phase28/RESULTS.md)를 참고하세요.
