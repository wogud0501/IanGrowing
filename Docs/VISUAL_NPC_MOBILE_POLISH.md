# 이안 키우기 비주얼·NPC·모바일 통합 검토

Unity 6000.6.8f1, macOS. 프로젝트의 실제 방·저장·일정·입력·장비 서비스를 사용했다. 검증용 저장 슬롯에 새 게임을 시작하고, 나이와 시각을 준비한 다음 실제 행동을 실행했다.

| 변경 영역 | 구현 및 근거 |
|---|---|
| 가족 외형 | 집안복, 외출복, 앞치마, 설거지와 청소 도구, TV를 보는 뒷모습, 잠옷을 기존 NPC 렌더러에 연결했다. [가족과 도시의 관찰 기록](NPC_ANIMATION_REVIEW.md) |
| 침대 수면 | 매트리스·몸·이불을 독립적으로 정렬했다. 접근, 앉기, 눕기, 덮기, 호흡, 걷어내기와 기상으로 이어진다. [Game View 연속 재생](VisualNPCMobile/Sleep-GameView.gif) · [수면 시험](SLEEP_ANIMATION_QA.md) |
| 도시와 품질 | 조명·그림자·비·노면 반사·월드 해상도·배경 인구를 조절하고 설정을 저장한다. [설정과 네 프리셋 원본](GRAPHICS_SETTINGS.md) |
| 모바일 | 하단 양쪽의 조작, 가운데 상태 게이지, 터치·키보드별 안내를 정리했다. [전후 화면과 안전 영역 시험](MOBILE_UI_QA.md) |
| 아트 제작 | Higgsfield GPT Image 2.6으로 수면 동작, 부모 외형·활동, 성장 단계별 잠옷, 침구, 싱크대 후면 자세, 현관에서 가방을 정리하는 동작을 생성했다. 선택한 프레임을 투명 픽셀 아틀라스로 정리했고 게임 내 침대와 배우에 따로 적용했다. [생성 ID·모델·원본 프롬프트](../ArtSource/Higgsfield/References/FamilySleep/manifest.json) |

**다시 고친 항목.** 첫 촬영에서 이불이 부모 얼굴을 가렸고, 기상 때 캐릭터가 매트리스 뒤로 들어갔다. 주방에서는 조리대가 손을 가렸으며 설거지용 접시가 두 번 그려졌다. 거실 TV 앞에서는 부모가 카메라를 보고 있었다. 침대의 실제 폭과 정렬 순서, 조리 자세, 설거지 시트, 착석 방향을 수정하고 재촬영했다. 터치 조작은 직사각형이 화면에 들어오는지에 더해 인벤토리가 실제 열리는지와 노치 여백을 함께 검사했다.

**회귀 범위.** PlayMode 12개 테스트가 통과했다. 이 가운데 실행한 기존 시나리오 목록은 142개 PASS, 11개 미구현, 6개 수동, 1개 BLOCKED였다. 격리 환경에서 복사할 기존 사용자 저장 파일이 없어 원본 파일 복사 시나리오가 차단됐다. 첫 실행의 새 게임 관련 실패 2개는 격리 테스트에 필수 약관 확인이 준비되지 않아 발생했다. 테스트에서 확인 전 상태를 보관하고 종료 시 복원하도록 수정한 뒤 재실행했다. 실제 플레이어의 동의 흐름은 그대로 사용한다. 에디터 검색 인덱스 초기화 중 QuickSearch 예외가 한 차례 이상 기록되어 게임 코드의 콘솔 결과와 구분했다.

실제 휴대기기에서의 프레임 유지와 발열, 시스템 제스처와 엄지 조작감은 미검증이다. [상세 결과와 실행 환경](VisualNPCMobile/Results.json)
