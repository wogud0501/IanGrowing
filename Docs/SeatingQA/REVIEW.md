# 정면 착석 검증

부모님 집의 같은 소파에서 이안·아버지·어머니를 먼저 검증했다. 캐릭터가 쿠션에 닿는 프레임, 대화 중 발이 놓인 바닥 좌표, 일어난 직후의 첫 걸음을 확인한 뒤 학교·직장·주거지 좌석을 검사했다.

## 원인과 재수정

- 거실에는 뒤에서 본 소파 그림, 위쪽을 향한 좌석, 등받이 전체를 복사한 앞가림 스프라이트가 같이 있었다. 정면 쿠션이 보이는 소파로 교체하고 TV도 실제 시선 방향에 배치했다. 기존 소파 충돌체를 유지하고 좌우 접근·골반·발 접점을 별도로 배치했다.
- 처음 정면으로 돌린 캐릭터는 여전히 바짓단이 수직으로 내려와 서 있는 것처럼 보였다. 양쪽 허벅지, 무릎, 바짓단, 손을 접는 그림을 만들고 원래 의상 색과 양쪽 신발을 사용했다. 성장 스프라이트마다 다른 여백과 피벗을 반영해 신발이 다리에서 분리되는 문제도 수정했다. [폐기한 첫 정면 시안](RejectedFrontPose.mp4)
- 측면에서 접근하는 아버지가 팔걸이에 걸리는 경우에는 소파 앞 통로를 먼저 지나도록 경로를 수정했다. 플레이어와 NPC가 같은 가구 접점을 사용한다. 보행용 몸체는 접근 위치에 두고 캐릭터 그림만 쿠션 위로 옮긴다. 좌석은 기립이 끝날 때까지 점유한다.
- 학교와 회사의 책상 그림에는 의자와 상판이 함께 들어 있다. 학교 의자는 책상 쪽을 향하도록 등받이와 학생의 투영 위치를 맞췄다. 사무용 의자는 모니터 뒤의 쿠션에 맞췄다. 식탁에서는 그림에 이미 포함된 의자와 그릇을 중복 생성하던 설정을 제거했다.
- 1인 원룸에서는 한 사람이 앉을 폭의 소파와 충돌체를 사용한다. 분리된 두 쿠션이 있는 구매형 소파와 대기 소파에는 각각의 접점과 예약 슬롯을 부여했다. 원래 캐릭터의 얼굴·머리·헤드폰은 기존 스프라이트를 사용한다.

## 검증 환경과 범위

Unity 6000.6.8f1 macOS Editor에서 등록된 게임 장면을 플레이했다. 별도 세이브에서 이안은 19세로 설정했다. 장소·관찰 시작 위치·시각·설치 가구는 재현 조건으로 지정했다. 녹화 중 착석과 기립은 실제 상호작용과 주민 일정이 실행했다. 동일한 테스트를 반복할 때는 게임 시간을 해당 일정에 맞춰 조정했다. 좌석 사용과 실제 상점 결제는 별개이므로 구매형 가구 검사는 소유·설치 상태를 복원한 세이브에서 진행했다.

목표 캡처 주기는 초당 30프레임이다. 각 원본 MP4와 이름이 같은 TSV 압축 파일에 매 프레임 경과 시간, 캐릭터, 월드 좌표, 포즈, 골반, 양발, 방향, 그리기 순서를 기록했다. 골반과 발은 렌더링된 캐릭터 메시의 관절 좌표다. 실루엣·가림·쿠션 접촉은 영상으로 함께 확인했다.

PlayMode 회귀 테스트 22개가 통과했다. 여기에는 기립 전 좌석 재예약 거절, 네 주거 프리팹의 쿠션·발·접근 위치, 가구 옆 위치 복원, 이동 경로 충돌, 기존 세이브 검사가 포함된다. 테스트 중 비활성 등받이에 남은 오래된 스프라이트 참조가 장면 로드 오류를 일으켜 참조를 제거한 뒤 전체를 다시 실행했다. [개별 테스트 결과](playmode.tsv)

실제 영상 범위는 위에 적은 캐릭터와 가구 조합이다. 이안의 모든 연령과 모든 가구의 조합, Windows·Android·iOS 빌드 및 실기기 재생은 **NOT VERIFIED**다.
