# 벤치와 가족 대화 종료 시 순간이동

수정 전 macOS 플레이어에서 두 제보를 재현했다. 서로 다른 행동이 LifeWorldController.Activity의 공통 종료 경로를 거쳤다. 이 경로가 시작 위치를 복원하면서 고정 반경 0.32로 충돌을 다시 검사했다. 성인 플레이어의 실제 발 충돌체 반경 0.28로는 설 수 있는 가구 가장자리를 막힌 곳으로 판정하면 Safe가 씬의 기본 스폰을 선택했다.

| 실제 월드 좌표 | 시작 | 수정 전 종료 | 수정 후 종료 |
|---|---|---|---|
| 도시 중심 공원 벤치 | (134.30, −8.42) | (130.00, 0.80) | (134.30, −8.86) |
| 소파에 앉은 아버지와 대화 | (493.60, −4.91) | (497.20, −6.45) | (493.60, −4.91) |
| 소파에 앉은 어머니와 대화 | (492.40, −4.91) | (497.20, −6.45) | (492.40, −4.91) |

- 일반 대화는 플레이어의 위치를 그대로 두고 행동·UI·입력 잠금만 해제한다. 상대방의 앉은 자세와 방향은 주민 스케줄러의 현재 좌석과 동작에 따라 표현한다.
- City_Center의 기존 `city-bench`에 WorldLifeAction을 연결했다. 플레이어와 주민은 벤치의 동일한 좌석 예약, 접근점, 착석점, 기립점을 사용한다. 휴식 보상은 기존 행동 서비스가 한 번 처리한다. 주택·상점·학교의 문 전환은 기존 전환 서비스가 맡는다.
- 행동 중 저장에는 해당 행동의 정지 위치 또는 전용 하차점을 사용한다. 도중 취소나 유효하지 않은 저장 좌표의 복구는 현재 성장 단계의 발 충돌체 오프셋·크기로 주변 바닥을 먼저 찾는다. 정상 완료한 대화에는 위치 복구 호출이 없다.
- Editor와 Development Build에서 행동 종료마다 상호작용 ID, 씬, 시작·종료 좌표, 위치 보정 사유와 씬 변경 여부를 기록한다. 그대로 서 있어야 할 행동에서 같은 씬 안에서 0.5 월드 유닛 넘게 이동하면 경고한다.
