# 이안 키우기 — 욕실 시각 재구성 패치노트

2026-11-14 · Phase2.8 신규 개발 없음.

- 사용자 콘셉트를 참고해 민트/아이보리 타일과 욕실 소품6개 모듈을 제작했습니다. 각 요소는 독립 Sprite와 GameObject이며 통배경을 사용하지 않습니다.
- 낮은 실내 시점에 맞춰 가족 욕실의 바닥 길이, 후벽·측벽·전면 문설주와 충돌을 정렬했습니다.
- 문짝을 덮던 배경판의 잘못된 Sorting을 수정했습니다. 기존 문 상태·경첩 개폐·Scene 이동은 보존하고 욕실 문 크기만 개별 스타일로 맞췄습니다.
- 이안을 유리 중앙 문살에서 비켜 정렬하고, 유리와 물의 세라믹 색 오염을 제거했습니다. 실제 진입·샤워·퇴장과 취소를 기존 생활 효과에 연결합니다.
-14개 실내의 공통 외곽 배경·접지 그림자와 카메라 원칙을 적용하고 Workspace 가구5업무석을 유지했습니다.
- 과도한 지갑/행동 안내 너비를 줄이고, 긴 한글 장소명의 줄바꿈을 수정했습니다.
