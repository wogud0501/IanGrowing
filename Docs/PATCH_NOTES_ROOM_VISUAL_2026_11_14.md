# 이안 키우기 — 실내 화면·카메라 복구 패치노트

2026-11-14 · Unity 6000.6.8f1 · Phase2.8 신규 기능 없음.

## 변경

- 가족 욕실의 바닥을5.2×3.8로 줄이고 후벽 반복 몰딩/과도한 높이를 정리했습니다.
- 분리된14개 실내에 공통 카메라 프로필과 정수 기준 확대·픽셀 위치 스냅을 적용했습니다. 작은 방과 큰 업무시설을 각각 프레이밍합니다.
- 방 밖의 어두운 clear 배경 대신 저대비 주택 벽체 표현을 추가했습니다. 방의 실제 이동/충돌 면적은 늘리지 않았습니다.
- 문 뒤의 검은 면을 밝은 안쪽 면으로 교체하고 바닥 문턱을 연결했습니다. 기존 경첩 볼륨, 문 상태·충돌·Scene 전환 코드는 유지했습니다.
- 샤워부스는 유리문 열기→안쪽 이동→문 닫기→기존 캐릭터 샤워/물 흐름→퇴장 순서로 동작합니다. 위생/시간 정산은 기존 경로가1회 처리하며 취소 시 점유와 입력을 복원합니다.
- 독립 욕실에 남아 있던 비활성 바닥/벽과 약0.064배 바닥 Scale 잔재를 복구했습니다. 개인 집의 옥색 타일은 유지했습니다.
- 침실/주방 창문을 벽 높이에 맞춰 정렬하고, 행동 진행 안내에 읽기 쉬운 공통 픽셀 패널을 적용했습니다.
- 편집기 재적용 때 문턱 장식이 중복되는 문제를 수정하고 생성 도구의 마지막 단계에 이번 설정을 연결했습니다.
