# 그래픽 설정과 비교 결과

메뉴 → 환경 설정 → 그래픽에서 품질을 선택한다. 프리셋에서 한 항목만 바꾸면 Custom으로 전환된다. 데스크톱 초기값은 High, 모바일 초기값은 Medium이다. 기존 모바일 저사양 설정이 켜진 기기는 Low에서 시작한다.

| 설정 | Low | Medium | High | Ultra |
|---|---:|---:|---:|---:|
| 월드 렌더 배율 | 75% | 87.5% | 100% | 100% |
| 기본 FPS 제한 | 30 | 45 | 60 | 120 |
| 강수 입자 | 정지 | 기본 강도의 65% | 100% | 135% |
| 비 오는 밤 가로등의 노면 반사 | 꺼짐 | 꺼짐 | 짧고 흐린 반사 | 길고 밝은 반사 |
| 시간대 조명·환경 장식·접지 그림자 | 최소 | 낮음 | 높음 | 가장 높음 |
| 시간대별 배경 인구 예산 배율 | 40% | 60% | 80% | 100% |

조명·날씨, 접지 그림자, 배경 군중, 월드 배율, 프레임 제한을 개별 설정할 수 있다. 기본은 Point 확대와 AA 끔이다. 사용자 선택 FXAA는 월드 카메라에 적용되고 HUD는 별도 화면 캔버스에 그린다. 프레임 제한 목록에는 데스크톱의 수직 동기화가 포함된다. 창/전체 화면과 모니터가 제공하는 해상도는 데스크톱 플레이어에서 제공한다. 설정은 기기 환경설정에 저장되며 저장 슬롯의 나이·경제·NPC 일정과 독립적이다.

차량 전조등은 야간에 켜지고 조명 품질에 따라 강도가 바뀐다. 실내 채광과 야근 조명은 게임 시각을 따르며, 줄어든 모션 설정에서는 강수 입자를 끈다. URP가 빌드에서 제외한 피사계 심도와 파니니 투영은 설정 메뉴에 없다.

**실측.** 동일한 도시 중앙 카메라를 21시와 비로 고정하고 각각 2초간 Game View의 제출 프레임을 세었다. 30.0 / 45.0 / 60.0 / 120.0 FPS였으며 차량과 보행자는 계속 움직였다. High와 Ultra가 축소 캡처에서 비슷하게 보여 실제 가로등 위치에 젖은 포장의 반사를 추가했다. 재촬영 시 Low/Medium은 반사 0개, High/Ultra는 각각 4개였고 폭 배율은 0.80과 1.25였다. 이 FPS는 설정한 프레임 상한의 동작을 검증한다. 모바일의 지속 성능·전력·GPU 프레임 시간은 미측정이다. **FXAA 빌드 검증.** macOS 독립 실행 플레이어에서 고정된 사선 패턴을 촬영했다. FXAA를 켜자 관찰 영역의 3,311픽셀이 모두 바뀌었고, 다시 끄자 첫 화면과 모든 픽셀이 일치했다. 아래 비교는 해당 영역을 최근접 방식으로 네 배 확대한 것이다. [Off → FXAA → Off 픽셀 비교](VisualNPCMobile/FXAA-Pixels.png)

별도의 격리 프로젝트에서 동선 회귀를 실행할 때는 이전 실행의 Custom 설정이 준비되지 않아 저장 검사가 한 차례 실패했다. 같은 프로젝트에서 게임 설정으로 120 FPS·최소 그림자·픽셀 모드를 지정하고 에디터 프로세스를 완전히 종료했다. 다음 실행에서 세 값과 Custom 표시가 복원됐으며, 검증 후 해당 환경의 기존 설정을 복구했다.
