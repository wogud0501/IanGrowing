# 이안 키우기 — BLACK COMEDY EDITION
# Phase 2.2 패치노트

작성일: 2026-11-04 (KST)  
대상: Unity 6.6 / 6000.6.7f1  
구현·Play Mode 검증·기존 저장 보존 확인을 마친 뒤 작성했습니다.

## 추가

- 메인 미션 60개와 6개 챕터 데이터를 등록했습니다. 011~020 원본 지정 명칭을 유지하고 나머지 제안 미션의 출처를 구분했습니다.
- 001~020을 실제 행동과 보상 수령으로 진행할 수 있습니다.
- 학교 입학, 독서, 친구 만들기, 숙제, 시험, 성적표, 방과 후 학습, 공부의 최소 행동을 추가했습니다.
- 미션 완료 시 나이가 성장합니다. 010 완료 후 7세, 019 완료 후 12세, 020 완료 후 13세가 됩니다.
- 플레이어 레벨/EXP와 나이를 분리했습니다. 날짜 경과만으로 나이가 오르지 않습니다.
- 현재 미션, 챕터 진행률, 보상 미리보기/수령, 완료 알림, 다음 미션과 60개 목록 UI를 추가했습니다.
- Bootstrap, MainMenu, Home, School을 구성했습니다. MainMenu → Home → School → Home 이동 중 능력치·재화·미션·보상 대기 기록을 공유합니다.
- GameContext와 SceneTransitionService가 서비스 수명, 로딩 화면, 경로 검증과 중복 이동을 관리합니다.

## 저장 및 안정성

- 저장 형식을 v4로 확장해 미션 진행도, 수령 기록, 성장 마일스톤, 해금, 활동 카운터와 중복 방지 ID를 저장합니다.
- 기존 v1/v2/v3 저장을 읽고 별도 v4 파일로 이전합니다. 구버전 원본을 강제 초기화하거나 덮어쓰지 않습니다.
- 수동 저장과 자동 저장을 계속 분리합니다. 저장 후 추가 행동을 해도 불러오기 버튼은 수동 체크포인트로 돌아갑니다. 재실행은 자동 저장을 이어갑니다.
- 완료/보상 중복 호출, 같은 활동 ID 재집계, 지연 보상 재진입을 방어했습니다.
- 새 게임은 0세/0G/부채 1,000,000G로 시작합니다. 기존 사용자 상태에는 신규 초기값을 강제 적용하지 않았습니다.
- 기존·신규 버튼 글씨의 중앙 정렬을 유지했습니다.
- 공식 이안 원본 이미지와 스프라이트를 그대로 보존했습니다.
