# 이안 키우기 UI 스타일 가이드

게임의 창을 생활 기록, 가계 명세서, 가방의 물품표처럼 다룬다. 제목과 잔액, 행동과 결과가 먼저 읽혀야 한다. 작은 활판 삽화는 기능을 찾는 단서로 사용한다.

| 용도 | 사양 |
|---|---|
| 종이 / 잉크 | 본문 바탕 #EFEADA, 글자 #263431, 제목 띠 #2E4242 |
| 선택 / 경고 / 보상 | 옥색 #376257, 인주색 #984D40, 보상지 #E7C48B. 설명, 수치, 포커스 커서와 조합한다. |
| 글꼴 | 기존 Galmuri 한국어 TMP 자산과 심볼 폴백. 본문 18~22, 창 제목 30, 강조 수치 32~35 기준 단위. 큰 글자 설정 115%. |
| 모서리 / 여백 | 32픽셀 원본에 6픽셀 9-slice 여백, 계단형 모서리. 종이 안쪽 여백은 본문 12~24 기준 단위. |
| 창 | 안전영역 내부 중앙 배치. 장부 창의 최대 너비 1,120, 최대 높이 780 기준 단위. |
| 시각 자산 | 6종 삽화를 한 장의 투명 아틀라스에 보관한다. Point 필터, 무압축, mipmap 없음. 표시 비율을 보존한다. |
| 피드백 | 옥색 선택면, 포인터 및 키보드 포커스, 누른 상태의 색과 픽셀 이동. 보상·손실에는 부호나 상태명이 동반된다. |
| 희귀도 | 기존 아이템 카탈로그의 등급명과 아이콘을 사용한다. 확률·천장·NEW는 게임 데이터에서 읽는다. |

HUD는 장소·시간, 현재 미션, 재화, 생존 수치와 주변 행동에 집중한다. 선택 가이드 상세, 금융 기록, 도움말은 각 창으로 이어진다. 캐릭터와 배경 위에 생성 이미지의 글자를 얹지 않는다.

본문 바탕은 아틀라스의 종이 색이다. 어두운 제목 띠 위의 밝은 글자는 #F9F4DF, 밝은 바탕의 보조 글자는 #2C5648, 경고 글자는 #913E35를 사용한다. 경고면 위에는 밝은 글자를 쓴다. 제목은 화면 용도, 큰 숫자는 현재 값, 보조 숫자는 조건과 누적치를 뜻한다.

창 전환은 비스케일 시간 150ms, 버튼 색 전이는 90ms, 눌림 이동은 1픽셀·100ms다. 알림은 최대 12단위 이동하며 140ms 진입·160ms 종료한다. 일반 알림은 설정에서 2~8초로 조절한다. 미션 완료는 기본 설정에서 1.4초다. 모션 줄이기와 키보드 포커스를 함께 지원한다. 그림 안에는 조작 지시나 필수 텍스트를 넣지 않는다.

좁은 화면에서는 CanvasScaler와 SafeArea를 먼저 적용하고 탭·상세·하단 행동이 같은 창에 남도록 한다. 폴더블과 태블릿의 장부는 1,120 기준 단위에서 폭을 제한한다. 본문·단추 18 이상, 작은 HUD 표기도 같은 TMP 최소 크기를 따르며, 긴 상세는 스크롤한다.
