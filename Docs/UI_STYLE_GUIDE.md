# 이안 키우기 UI 스타일 가이드

2026-11-21 기준. 도시와 이안은 기존 픽셀 팔레트를 사용한다. 그 위에 나타나는 생활 기록, 물품표, 거래 명세서는 검정·흰색·회색으로 통일한다. 처음 보는 플레이어도 제목, 현재 값, 가능한 행동 순서로 읽을 수 있어야 한다. [실제 여섯 화면](../ArtSource/UI/Monochrome/Review/UIFamily.jpg)

| 용도 | 기준 |
|---|---|
| 바탕과 면 | 창은 #202020 계열, 제목과 깊은 입력면은 #101010 계열, 보조면은 #282828~#484848. HUD는 어두운 반투명 면으로 월드를 남긴다. |
| 글자 | 제목과 핵심 값 #F4F4F4, 본문 #DDDDDD, 보조 #B8B8B8, 비활성 #A0A0A0, 반전 글자 #101010. 흰색은 선택·강조·작은 반사광에 집중한다. |
| 한글 | Galmuri TMP와 심볼 폴백. 본문·버튼은 기준 18 이상, 제목 약 30, 잔액 35, 부채·순자산 27. 큰 글자는 기준의 115%. 긴 본문은 줄을 바꾸고 마지막 줄까지 스크롤한다. |
| 외곽선과 간격 | 32×32 픽셀 타일의 6픽셀 9-slice 여백. 계단형 모서리와 가는 안쪽 테두리, 12~24단위 본문 여백. 인셋은 입력·내용, 밝은 표본 받침은 물건의 실루엣에 사용한다. |
| 아이콘 | 16픽셀 생존 심벌과 글자·수치를 짝짓는다. 탭과 메뉴는 기능명과 픽셀 그림을 같이 쓴다. 그림에는 필수 텍스트를 굽지 않는다. |
| 수치 | 금액은 천 단위 구분과 G, 증감은 부호와 ▲/▼. 주식은 밝은 실선·점선과 수치를 사용한다. 루비 숫자는 다른 잔액과 같은 잉크다. |
| 상태 | 현재 탭은 밝은 면과 검정 글씨, 키보드 포커스는 테두리. 눌림은 깊은 면, 비활성은 낮은 대비의 면과 글씨. 토글은 ‘켜짐/꺼짐’과 필드 반전을 함께 쓴다. |
| 희귀도 | 등급명과 데이터의 rank 0~4에 대응하는 다섯 테두리로 구별한다. 상위 결과를 공개할 때 무채색 명암이 변한다. 가방에서 장착은 모서리 표식과 글자, 수량과 NEW는 별도 표기한다. |
| 창 크기 | 공통 장부의 최대 너비 1,120·높이 780 기준 단위. 세로 화면은 동적 판형, 큰 화면은 폭 제한, 대화와 계산대는 아래쪽 상황 창을 사용한다. |
| 모션 | 창 150ms. 버튼 누름은 1픽셀·100ms. 알림 진입 140ms·종료 160ms, 표시 시간 2~8초. 미션 완료는 기본 약 1.4초이며 앞에 짧은 흰 선이 지나간다. 줄인 모션에서는 가챠 결과를 즉시 읽을 수 있다. |
| 음향 | 기존 열기·닫기·선택·확정·취소·경고·미션·업적 훅을 재사용한다. 필수 정보는 글자와 모양으로도 전달한다. |

금융은 잔액과 부채를 먼저 보여주고 납부 내역은 아래에 둔다. 상태와 행동이 분명해진 뒤에만 짧은 문구를 덧붙인다. 대표 문구는 ‘납부 완료 · 사회가 정상적으로 작동하고 있습니다.’다.

주택 사진, 상점의 실제 물품, 대화 상대와 월드에는 원본 색이 보일 수 있다. 가방·가챠는 UI에 표시하는 표본에만 무채색 재질을 쓴다. 공통 창의 경고는 문구와 테두리로 구별한다. [Higgsfield 기준 이미지](../ArtSource/UI/Monochrome/Masters) · [측정한 창 내부 색 비율](../ArtSource/UI/Monochrome/Review/NeutralPixels.json)
