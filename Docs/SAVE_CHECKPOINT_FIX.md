# 수동 저장 체크포인트 / 버튼 정렬 수정
원인: GameManager의 행동/종료 자동 저장이 수동 저장 버튼과 같은 파일을 덮어썼음.
수정 전 실제 재현 실패: 2일차 수동 저장 -> 행동 3회 -> 수동 파일이 5일차로 변경됨.
이전 검증은 이 자동 저장이 켜진 사용자 순서를 놓쳤음.

## 동작
- 저장 버튼: 수동 체크포인트 파일 갱신. 자동 재개 지점도 현재 상태로 맞춤.
- 행동/종료/일시정지 자동 저장: 별도 .autosave.json 파일만 갱신.
- 불러오기 버튼: 수동 체크포인트만 복원. 복원 뒤 자동 저장도 그 상태로 맞춤.
- 게임 시작: 자동 저장이 있으면 이어서 진행, 없으면 수동/기존 저장 경로로 복원.
- 새 인생은 자동 저장만 갱신하며 이전 수동 체크포인트를 자동으로 삭제하지 않음.
- 이번 수정 이전에 자동 저장으로 이미 덮인 과거 수동 시점은 구분 정보가 없어 소급 복구를 보장하지 않음.

## 검증
1. 저장 -> 행동3회(자동 저장 켜짐) -> 불러오기: 날짜/8개 스탯/경제/성장/위험/상태/소수 시간 정확 복원.
2. 행동 중 수동 파일 바이트 불변.
3. 반복 불러오기 동일 체크포인트 복원.
4. 다음 명시적 저장만 수동 체크포인트 교체.
5. 실제 Play 종료/재진입: 자동 4일차로 재개 후 수동 불러오기는 2일차로 복원.
6. Phase2 검증 45개, Phase1 호환 검증 40개 재통과. 기존 자동 저장 검증은 자동 채널을 읽도록 수정.
7. 11개 버튼 텍스트의 가로/세로 Center 및 버튼/텍스트 중심 좌표 일치 확인. 실제 화면 확인.
8. _Game 컴파일/런타임 오류 없음. 외부 Unity AI NoSubscription 메시지는 별도 존재.
