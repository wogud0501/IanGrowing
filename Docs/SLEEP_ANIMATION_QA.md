# 이안과 가족의 수면 검증

Unity 6000.6.8f1 Game View에서 부모님 집의 아기 침대와 일반 침대, 독립 집 침대, 부모 침실의 두 침대를 재생했다. 화면에서 이불이 올라가는 중간 프레임, 완전히 덮인 프레임, 기상 중간 프레임을 각각 캡처했다. [성인 이안의 수면·기상 연속 재생](VisualNPCMobile/Sleep-GameView.gif) · [독립 집 수면과 회전한 침대](VisualNPCMobile/Sleep-Sequence.jpg) · [부모 침실](VisualNPCMobile/Family-Activities.jpg)

| 검증 | 관찰 결과 |
|---|---|
| 이안 0·1·3·8·14·19·35·65세 | 여덟 연령에서 실제 침대 행동을 시작했다. 이불 덮기와 걷기를 거친 뒤 시간이 진행되고 조작이 복귀했다. 0세는 보호자의 돌봄 위치에서 시작한다. |
| 침대 방향 | 독립 집에서 침구 방향을 90도 바꿔 재생했다. 얼굴·어깨·이불 발끝이 함께 회전하는 것을 확인했다. |
| 아버지·어머니 | 23시 55분 각자 침대를 사용했다. 06시 45분 어머니와 06시 55분 아버지가 각자의 일정에 따라 이불을 걷었다. |
| 중복 실행 | 같은 침대에서 진행 중 다시 누른 수면 요청을 여덟 번 모두 거부했다. NPC의 침대 예약은 일어나 침대 옆으로 나올 때까지 유지한다. |
| 수면 도중 저장·복귀 | 이불을 올리는 중 자동 슬롯에 저장하고 실제 데이터를 다시 불러왔다. 이불 덮임은 0, 조작은 가능, 경과 시간과 장착 슬롯은 저장 당시 값이었다. |
| 장착한 헤드폰 | macOS 개발 빌드에서 실제 헤드폰을 장착한 채 수면했다. 덮고 있는 동안 장착 데이터가 유지됐고 화면에서 헤드폰이 숨었다. 기상 후 조작과 장착 상태가 복구됐다. |
| 아트 회귀 | 11개 외형 단계 각각에 대해 구분되는 수면 프레임 5개, 아틀라스 경계, 이불의 Point 필터를 PlayMode 테스트에서 검사한다. |

**구현과 재검토.** 보행 가능한 이안은 접근점에서 앉고 상체를 기울인 뒤 베개에 눕는다. 발쪽에 고정한 퀼트 상단이 어깨를 향해 올라간다. 수면 중 몸과 천은 한 호흡 주기를 공유한다. 기상할 때는 천이 먼저 내려가고 집안복과 이동이 복귀한다. 침구는 빈 침대에도 접힌 상태로 남는다. 수면 시간·회복·미션 정산은 기존 행동 서비스가 담당한다.

첫 재생에서는 부모 침대의 투명 여백까지 이불이 덮었고, 기상 첫 프레임에서 아버지가 매트리스 뒤로 들어갔다. 침대 스프라이트별 실제 폭, 매트리스 좌표계의 어깨 위치, 기상 중 캐릭터 정렬 순서를 수정한 뒤 다시 촬영했다. 측정 지점과 실제 스크린샷을 함께 확인했다. 범용 침대를 쓰는 다른 주민도 같은 이불 렌더러를 사용한다. 얼굴과 이불 경계의 개별 육안 판정은 이안과 부모에게 수행했다.
