# 일반 상호작용 위치 회귀 검증

2026-11-22, Unity 6000.6.8f1. 기존 버전과 수정 버전에서 같은 오브젝트와 같은 접근 방향을 사용했다. 재현용 입력 도구로 캐릭터 발이 들어갈 수 있는 경계 좌표에 세운 뒤 실제 사용 입력 또는 대화 선택지를 실행했다. 시작·종료 좌표, 활성 씬, NPC 자세, 다음 동작과 저장 후 재접속 결과를 확인했다. 테스트용 저장 슬롯은 실사용 슬롯과 분리했다.

| 검증 대상 | 실제 결과 |
|---|---|
| 도시 중심 공원 벤치 | 수정 전에는 도로 건너 도시 기본 스폰으로 이동했다. 수정 후 성인과 9세 모두 같은 벤치의 기립점에서 일어났다. 키보드 E와 Android 화면의 사용 버튼으로 확인했다. 착석 중 E를 다시 눌러도 휴식 완료는 한 번만 기록됐다. |
| 다른 휴식 지점 | 회사 휴게 좌석, 금융·부동산 대기석, 부모님 집 소파에서 각각 사용한 지점 근처에 남았다. 현재 주거 골목에는 플레이어가 쓸 수 있는 공공 벤치가 없다. |
| 부모님 집 대화 | 아버지·어머니 모두 소파에서 TV를 볼 때 대화 후 같은 좌석과 자세를 유지했다. 반복 대화, 식사 중인 아버지, 청소 중인 아버지·어머니, 설거지 중인 어머니도 확인했다. 집안일을 계속하는 부모는 기존 일정에 따라 다음 위치로 걸었다. |
| 친구 대화와 성장 | 학교에서 친구와 실제로 대화해 M014를 완료하고 8세에서 9세로 성장해도 위치가 (256.60, −1.04)로 유지됐다. 보상을 받고 M015로 진행했다. |
| 생활과 수업 | 가족 주방의 음식 준비·식탁·설거지, 학교 정수기, 독서·공부를 확인했다. 서서 하는 행동은 위치를 유지했고 의자에서 하는 수업은 책상 옆 기립점으로 돌아왔다. 상점에서 빵 한 개를 구매하고 보유 금액이 730G에서 710G로 바뀌는 동안 계산대 앞 좌표도 그대로였다. |
| 컴퓨터와 근무 | 취업한 19세 상태를 별도 QA 슬롯에 구성하고 회사 컴퓨터에서 정상 메뉴로 8시간 근무했다. 09시 15분부터 17시 15분까지 진행한 뒤 같은 사무실 책상 옆 (226.92, −4.07)에서 조작이 복귀했다. 금융 단말기를 열고 닫을 때도 단말기 앞 위치를 유지했다. |
| 침대·문 | 부모님 집 침실과 독립 집에서 수면과 기상 뒤 침대 옆에 섰다. 부모님 집 안쪽 문, 독립 집 현관에서 골목으로 나가기, 도시에서 학교·회사로 들어가기를 확인했다. 회사 휴게 공간은 사무실 내부에 있다. |
| 저장·종료·이어하기 | 도시 벤치에서 저장한 뒤 재실행했을 때 벤치 옆 (134.30, −8.87)을 복원했다. 어머니와 대화한 직후 별도로 저장·재실행했을 때도 소파 옆 (492.40, −4.91)을 복원했다. 두 번 모두 게임 날짜를 유지했다. |

| 실행 환경 | 검증 범위 |
|---|---|
| macOS Unity Editor Game View 및 macOS 플레이어 | 수정 전후 위치 비교, 좌석·대화·생활·문, 날짜, 한글, HUD·메뉴 실화면 |
| Android API 35 에뮬레이터, 1080×2400 | 터치 입력, 가족·벤치와 친구 미션, 자정, 세로 HUD 재배치와 최종 화면 |
| iPhone 시뮬레이터, 1206×2622 | 모바일 입력 경로, 가족·벤치와 친구 미션, 자정, HUD 글자와 지도·재화 배치 |
| Windows x64 플레이어, Wine | 그래픽 초기화 제약으로 헤드리스 실행. 벤치·가족·친구·수업·상점의 게임 로직을 확인했다. Windows 네이티브 화면과 모바일 물리 기기 조작감은 **NOT VERIFIED**. |
