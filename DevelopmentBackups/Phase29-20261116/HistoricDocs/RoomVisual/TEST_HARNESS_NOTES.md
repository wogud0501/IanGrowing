# 테스트 하네스 수정 이력

실행 중 확인한 세 가지 하네스 가정을 수정했다. 게임 기능의 성공으로 위장하지 않았으며 실패 로그와 최종 실행 결과를 구분했다.

1. 회사 화장실에는 샤워가 없다. Single(Shower) 예외가 발생해 실제 샤워가 존재하는 가족/개인 욕실만 실행 대상으로 수정했다.
2. WorldDoor를 disable하면 solid leaf 렌더러도 의도대로 꺼진다. 비활성화한 뒤 비주얼이 보이는지 검사하던 잘못된 반복 테스트를 수정했다. 실제 활성 상태로3종 각각30/60Hz dt에서20회씩 총120회 실행했고 root/frame/충돌/비주얼 검사 통과 후, 거리 연결에 Door component가 없다는 별도 가정에서 중단됐다. INITIAL_DOOR_HARNESS_FAILURE.json의 통과 항목이 이 반복 검사의 근거다. 최종30개 장소 연결은 roomVisualDoors에서 별도 모두 완료했다.
3. 좁은 욕실의 출입구에서 터치 버튼을 누르면 실제 문 상호작용이 바로 시작되어 터치 컨트롤이 잠시 숨겨지고 held 값이 해제된다. binding의 held 값을 검사하는 프로브를 실제 상호작용 반경 밖의 욕실 안쪽으로 옮겼다. 이는 게임의 문/입력 코드를 변경하거나 사용 조건을 우회한 수정이 아니다. INITIAL_MOBILE_INPUT_FIXTURE_FAILURE.json에는 수정 전 실패가 남아 있다.
