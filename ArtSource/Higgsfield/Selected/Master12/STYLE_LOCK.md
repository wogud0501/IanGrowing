# 이안 키우기 마스터 레퍼런스

새 장소의 인물은 이안·시민 시트에서, 거리의 구조는 주거 골목에서, 실내의 카메라와 그림자는 독립 집에서 가져온다. 같은 장소를 다른 시간에 그릴 때는 그 장소의 선정 PNG를 첫 이미지 입력으로 사용한다. [마스터 콘택트 시트](Review/Master_Contact_Sheet.jpg) · [픽셀 제작 보드](Review/Master_Pixel_Board.png) · [생성 기록](manifest.json)

## 캐릭터와 카메라

- 이안의 기준은 사용자 원화다. 헝클어진 앞머리, 반쯤 감긴 눈, 목의 이어컵, 검은 반팔, 카고 바지와 슬리퍼가 네 방향에서 같은 사람으로 읽혀야 한다. 19세 실루엣의 기준은 다리를 늘리고 머리 비율을 줄인 B 교정본이다. [공식 원화](../../../../Assets/_Game/Art/Characters/Ian/Reference/Ian_OfficialDesign.png) · [턴어라운드](IAN_MASTER_YOUNGADULT.png)
- 가로로 이어지는 길, 바닥과 남향 벽이 함께 보이는 시점, 앞쪽이 열린 실내를 유지한다. 현관에서 목적지까지 인물이 지나갈 길을 먼저 확보한다. 거리 전경과 실내는 줌이 다르므로 그림 전체의 출력 해상도로 인물 크기를 재지 않는다.
- 사람과 문, 사람과 벤치, 소형차와 버스를 한 쌍으로 놓고 크기를 판단한다. 이안 시트는 정지 외형과 네 방향의 기준이며, 걸음 주기는 기존 Unity 애니메이션에서 관리한다.
- 7종 중간 검수에서는 실제 배경 키 색을 제거한 보드를 함께 보았다. 주거 블록의 벽돌·몰탈·보도, 편의점 형광등, 주민의 저채도 옷, 차체와 벤치의 금속 하이라이트를 공통 기준으로 채택했다. [첫 7종](Review/Core_Seven.jpg) · [키 색을 제거한 보드](Review/Seven_Pixel_Board.png)

## 픽셀과 조명

- 원본 PNG는 구도와 광원의 레퍼런스다. Pixel 폴더에는 용도별 논리 해상도에 맞춰 리샘플링한 12장이 있다. 12장의 공통 192색 팔레트를 사용하고 디더링을 끄고, 크로마키 바탕은 회색으로 치환했다. 캐릭터와 차량을 크게 보여 주는 시트의 확대 배율은 로케이션과 다르다. [픽셀 원본](Pixel) · [8개 실내외 장소에서 추출한 대표색](Review/Scene_Palette.png)
- 차도는 잉크빛 남회색, 보도와 벽은 바랜 회갈색, 생활 조명은 따뜻한 노랑으로 읽힌다. 차가운 형광등 아래의 편의점 상품, 목재와 옥색 타일이 있는 집, 중립색 사무실에 각각 다른 밝기 범위를 둔다. 간판 문구와 가격은 Unity의 한글 레이어에서 처리한다.
- 블랙코미디는 길을 막지 않는 두 번째 디테일에 둔다. 독립 집의 빈 바닥 옆 고지서, 환한 사내 포스터 옆 업무 책상, 학교의 진로 게시판과 엎드린 학생이 그 기준이다.

## 실제 Game View와 비교

| 장면 | 관찰 | 제작 기준 |
|---|---|---|
| 독립 집 · 부모님 집 | 플레이 화면에서는 나무 바닥이 크게 보이고 부모님 집의 조리 공간이 단순하다. | 독립 집의 여백은 살린다. 가족의 집은 밥솥·수납·식탁처럼 사용자가 누구인지 드러내는 물건으로 밀도를 만든다. |
| 주거 골목 · 도심 | 실제 카메라는 보도와 차선을 잘 보여 준다. 마스터에는 보도 뒤 현관, 유리창 너머 사람과 이웃 건물이 더 많이 보인다. | 통행 폭과 횡단보도를 유지한다. 생활 소품은 배경과 겹칠 때도 발밑 실루엣이 남아야 한다. |
| 편의점 | 현재 플레이 화면은 진열대 사이가 넓다. 마스터에서는 냉장고와 창가 식사대의 색온도가 공간을 나눈다. | 통로에서 계산대가 보이게 하고 상품은 작은 색 블록으로 처리한다. |
| 학교 · 회사 · 금융 | 게임은 가구 간격이 넓고 바닥이 지배적이다. 마스터는 칠판·프린터·상담 창구 등 벽면 기능으로 장소를 구분한다. | 벽면 소품과 실무자 자세로 장소를 구분하고, 플레이어 바로 앞에는 진입 가능한 여백을 둔다. |

왼쪽은 프로젝트에서 캡처한 실제 Game View, 오른쪽은 해당 장소의 선정 레퍼런스다. [8개 장소 비교](Review/Game_View_vs_Master.jpg)

## Unity 적용

차량 7종과 거리 소품 14종을 개별 투명 PNG로 분리했다. 런타임 적용 대상은 주거 골목에 이미 놓인 벤치와 배전함이다. 각 프리팹의 기존 콜라이더와 정렬을 사용한다. 따로 놓인 물체를 한 장의 배경으로 합치지 않는다. [분리된 21종](Review/Cutout_Board.png) · [출처와 크롭 영역](Cutouts/index.json) · [Unity 적용 경로](Review/Unity_Sprites.json)

두 초기 후보와 수정 이력은 아래 보드에서 원본 구도로 비교할 수 있다. [핵심 7종 A/B](Review/Candidate_Review_1.jpg) · [확장 5종 A/B](Review/Candidate_Review_2.jpg) · [이안·집·은행의 교정 전후](Review/Targeted_Edits.jpg)

주거 골목의 같은 위치에서 19세 이안과 두 소품을 정오에 촬영했다. 벤치와 배전함 모두 플레이 카메라 안에 있었고, 기존 프리팹이 새 스프라이트를 렌더링했다. 두 차례 전용 테스트 슬롯 실행 후 기존 저장 파일 지문이 같았다. [Game View 전후](Review/Residential_Before_After.jpg) · [Play Mode 결과](Review/Residential_After.json) · [임포트·아틀라스 결과](Review/Unity_Import.json)
